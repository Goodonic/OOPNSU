## 02.I

`reference_version::add` принимает первое слагаемое по ссылке `int&` и записывает в него сумму. Поэтому после вызова значение меняется в `main`. Второе слагаемое передаётся через `const int&`.

Функции `add` и `modified_add` принимают оба слагаемых через `const int&`: аргументы передаются без копирования, а изменить их через эти параметры внутри функции нельзя. В `main` показаны значения до и после вызовов.

## 02.II

Обычная и модифицированная функции называются `add`, возвращают `int` и принимают два аргумента `const int&`. Они находятся в пространствах имён `original` и `modified`, поэтому обе реализации можно вызвать из одного `main`.

## 02.III

В обоих пространствах имён есть перегрузки `add` для `int` и `double`. Компилятор выбирает нужную реализацию по типам переданных слагаемых. В этой части шаблоны ещё не используются.

## 02.IV

Обе функции переписаны как шаблоны с типом `T`. В `main` показаны вызовы `add<int>` и `add<double>`. Определения шаблонов находятся в заголовочных файлах, чтобы компилятор мог создать функции с нужными типами в месте вызова.

Во всех частях модифицированная функция с вероятностью 50% прибавляет к сумме случайное число от 1 до 10 через `<random>`.

Для `Part1` и `Part2` введи, например, `2 3`. Для `Part3` и `Part4` введи `2 3`, затем `1.5 2.25`. Обычные результаты — `5` и `3.75`.
