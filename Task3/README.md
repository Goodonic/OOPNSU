## 3.I

В шаблоне два типа: `ResultType` задаёт тип результата, `ArgumentType` — тип слагаемых. Тип аргументов компилятор определяет сам. Например, `original::add<double>(first_addend, second_addend)` принимает два `int` по константным ссылкам и возвращает `double`.

Определения шаблонов находятся в заголовочных файлах: они нужны компилятору в месте вызова для создания функции с выбранными типами.

В `main.cpp` показаны преобразования `int → double`, `int → float` и `double → int` для обычной функции и функции с рандомом. При преобразовании в `int` дробная часть суммы отбрасывается. Модифицированная функция с вероятностью 50% прибавляет случайное целое от 1 до 10 до преобразования результата.

Для проверки введи `2 3`, затем `1.75 2.75`. Обычные результаты: `5.00`, `5.00` и `4`.

## 3.II

`new int(42)` выделяет память для одного числа. Два обычных указателя сначала содержат адрес этого числа. После `delete` второй указатель становится висячим: память освобождена, но старый адрес остался. Разыменование такого указателя вызывает неопределённое поведение, повторное удаление — двойное освобождение. Программа показывает момент появления висячего указателя и затем присваивает ему `nullptr`.

Массив создаётся через `new int[6]` и заполняется числами `10 20 30 40 50 60`. Для вставки `99` в середину выделяется новый массив на 7 элементов, значения копируются со сдвигом, прежняя память освобождается. Получается `10 20 30 99 40 50 60`. Для одного значения используется `delete`, для массива — `delete[]`. После освобождения указатели обнуляются.

## 3.III

`unique_ptr` единолично владеет объектом. При `std::move` владение передаётся другому указателю, исходный становится пустым. `reset()` освобождает объект и обнуляет указатель. `unique_ptr<int[]>` освобождает массив при выходе из блока.

`shared_ptr` сохраняет объект, пока существует хотя бы один владелец. `weak_ptr` наблюдает за объектом, но не продлевает его жизнь. Метод `lock()` возвращает `shared_ptr`: если объект уже удалён, результат пустой. Проверка результата позволяет обращаться только к существующему объекту. Сохранённые отдельно обычные указатели всё ещё могут стать висячими.

## 3.IV

Выбраны `T1 = int`, `T2 = double`, `M = 6`, `N = 10`. Параметры находятся в начале `Part4/main.cpp`.

Второе слагаемое генерируется один раз в диапазоне `[-10, 10]` и одинаково для всех контейнеров. Значения первого слагаемого генерируются отдельно для каждого элемента.

| Исходный контейнер | Форма обхода | Контейнер результатов |
| --- | --- | --- |
| `array<int, 6>` | Классический `for` | `vector<double>` |
| `vector<int>` | `for` с итератором | `list<double>` |
| `list<int>` | Range-based `for` | `deque<double>` |
| `deque<int>` | Классический `for` | `array<double, 6>` |

Последний цикл `for` одновременно проходит по всем восьми контейнерам и формирует строки таблицы. Программа выводит таблицу и записывает её в `containers.md` в рабочей папке запуска. При следующем запуске файл перезаписывается новыми случайными данными.

Пример созданного файла: [Part4/containers.md](Part4/containers.md).
